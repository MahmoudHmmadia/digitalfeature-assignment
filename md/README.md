# FeedbackHub Documentation

- `TASK_CONTEXT.md` is the working interpretation of the supplied assignment.
  The original PDF remains authoritative.
- `DECISIONS.md` records architectural choices, alternatives, and consequences.
- `SCOPE.md` states what is complete, incomplete, assumed, and planned next.
- `AI_COLLABORATION.md` explains the developer/AI division of labor and gives
  concrete examples of the workflow.

Operational setup and the current feature list are in the repository root
`README.md`. Container and Kubernetes instructions are in `deploy/README.md`.
